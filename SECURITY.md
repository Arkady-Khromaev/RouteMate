# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in RouteMate, please report it responsibly.

Please do not disclose sensitive security vulnerabilities publicly through GitHub Issues.

Instead, contact the project maintainers privately through GitHub.

When reporting a vulnerability, include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact.
- Any relevant screenshots or logs.

We appreciate responsible disclosure and the efforts of contributors to keep RouteMate secure.

## Supported Versions

Security updates are provided for the latest version of RouteMate.
